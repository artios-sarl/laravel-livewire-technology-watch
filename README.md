# Technology watch on Laravel with Livewire

This repository is a technology watch on Laravel with Livewire. It contains what could be useful for a project using these technologies.

## Prerequisites

The following prerequisites must be filled to run this service:

- [Docker](https://docs.docker.com/get-docker/) must be installed.
- [Docker Compose](https://docs.docker.com/compose/install/) must be installed
  (it should be installed by default with Docker in most cases).
- [Visual Studio Code](https://code.visualstudio.com/download) must be
  installed.
